# Web Share API Demo

This will demostrate the web the [Web Share API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Share_API) to share a GPX file.

If the share API isn't supported on the device, it will simply download the file.  However, if sharing is available, the user should be able to directly share the file with other applicaitons.
